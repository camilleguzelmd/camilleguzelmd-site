# Accessibility notes — Camille Guzel MD site v0

Unpublished. Local files only. `noindex, nofollow` in the document head.
Form does not post. When live: BAA’d Workspace Sheet only — see HOSTING.md. No bot/Cursor/personal Gmail capture.

## Palette and contrast (WCAG 2 relative luminance)

Pairs in use. Nothing else is used for type or essential UI. No cream/sage.

| Foreground | Background | Hex | Ratio | Normal text | Large text | UI |
|---|---|---|---|---|---|---|
| ink | white | `#1C1418` on `#FFFFFF` | **18.06:1** | AAA (≥7:1) | AAA | pass |
| white | plum | `#FFFFFF` on `#25141C` | **17.57:1** | AAA (≥7:1) | AAA | pass |
| plum | white | `#25141C` on `#FFFFFF` | **17.57:1** | AAA (≥7:1) | AAA | pass |

Ink on plum is **1.03:1** and is not used.

### Computation

WCAG 2 relative luminance and contrast, sRGB.

```
channel_lin(c) = c/12.92                     if c ≤ 0.04045
               = ((c+0.055)/1.055)^2.4       otherwise
  where c is the 0–1 sRGB channel.

L = 0.2126 R + 0.7152 G + 0.0722 B
contrast = (L_lighter + 0.05) / (L_darker + 0.05)
```

| Color | RGB | L |
|---|---|---|
| white `#FFFFFF` | 255, 255, 255 | 1.0000 |
| ink `#1C1418` | 28, 20, 24 | 0.00813 |
| plum `#25141C` | 37, 20, 28 | 0.00977 |

Ink on white: (1.0000 + 0.05) / (0.00813 + 0.05) = **18.06:1**
White on plum: (1.0000 + 0.05) / (0.00977 + 0.05) = **17.57:1**

Focus rings use `currentColor` (ink on white, white on plum), 3px solid, 4px offset. Same AAA pairs.
Hairlines are 2px in currentColor.
Submit is white on plum (17.57:1); hover is white on ink (18.06:1).
CG initials (hero/nav) are white on plum at full opacity (17.57:1). About uses interim headshot photo.

Goniometer watermark is 14% ink on white (`≈ #DFDEDF`). Decorative only (`::before`, not type). Contrast vs white is ~1.34:1 by design. Hidden below 1100px so it cannot sit under letters. On wide screens it sits in the right-edge field of white sections only — never on plum.

## Text, not images of text

All copy is real HTML in Atkinson Hyperlegible via `@font-face`
(`fonts/AtkinsonHyperlegible-Regular.ttf`, `fonts/AtkinsonHyperlegible-Bold.ttf`).
`font-display: swap`. No tracking. Body 1.25rem / 1.55. No photographs.

## Structure

- `lang="en"`
- Skip link is the first focusable control; visible on `:focus-visible`; target `#main` (`tabindex="-1"`)
- Landmarks: `header`, `nav` (aria-label Primary), `main`, labelled `section`s, `footer`
- One `h1` (“Camille Guzel, MD”), motto “you are capable.” as styled text (not clinic name), then `h2` Care / About / Opening in 2026 / Contact, then `h3` in Care
- Lists for specialties and contact
- `tel:` and `mailto:` links; website printed as text (site is not live)
- About uses an interim headshot (`assets/headshot-interim.jpg`) with descriptive `alt`. Temporary until professional photos. Hero/nav still use high-contrast CG marks.

## Form (preview only)

- Every field has a visible `<label>` or `fieldset`/`legend`. No placeholder-only labels.
- Required vs optional is in the label/legend text, not color alone.
- Role is a native radio group: future patient / referring MD / PT / other.
- Interest is checkboxes: waitlist and/or clinic updates (no free-text clinical story).
- Autocomplete: `name`, `email`, `tel`.
- Submit never posts. `preventDefault` + live region (`role="status"`): “This form is a preview — not collecting yet.”
- Privacy copy on the page: don’t send health details; no spam; we won’t sell your information.
- No PHI fields. No diagnosis field. No free-text note. No practice/city fields.
- Live destination (after sign-off + CoS hosting): Camille’s BAA’d Google Workspace Sheet/Drive only. See `HOSTING.md`. Bots never read submissions.

## Target size

Interactive controls are `min-height` / `min-width` **44px** (WCAG 2.5.5 Target Size AAA):

- Skip link
- Brand lockup
- Primary nav links
- Hero Call / Email buttons
- Radio and checkbox rows (the label is the hit target)
- Text, email, tel, textarea (`min-height: 44px`)
- “Keep me posted”
- Contact list links
- CG marks used as brand (44×44 px minimum; larger in hero/about)

On viewports ≤479px the hero actions stack and go full width.

## Motion and focus

- `:focus-visible` outline on all interactive elements
- Skip link off-screen until focused
- `prefers-reduced-motion: reduce` sets `scroll-behavior: auto` and collapses animation/transition duration
- No carousels, no autoplay, no parallax
